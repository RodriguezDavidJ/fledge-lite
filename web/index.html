Fledge Lite The Fledge GUI and core REST API running entirely in this tab (Pyodide + a service worker). Nothing is sent to a server. An unofficial experiment, not affiliated with the Fledge project.

Starting…

First load downloads about 13 MB (Python, aiohttp, the Fledge core and GUI). After that the browser caches it.

Configure with the URL, for example ?south=simpump&rate=2, ?csv=<url>, ?setup=<url>, ?plugin=<url of a .py plugin> or ?gist=<id>. All options.
